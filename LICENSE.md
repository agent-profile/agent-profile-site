# Licensing

Agent Profile uses separate licenses for documentation material and software
material.

Unless a file contains a different license notice, path-specific rules take
precedence over general material categories:

- Files under `src/content/`, Markdown documentation wherever located,
  examples, and authored images, diagrams, and other documentation assets are
  licensed under the [Creative Commons Attribution 4.0 International
  License](LICENSES/CC-BY-4.0.txt).
- Files under `public/schemas/`, Astro components and layouts, styles, source
  code, scripts, tests, configuration, and workflows are licensed under the
  [Apache License 2.0](LICENSES/Apache-2.0.txt).
- Third-party material remains subject to its original license and attribution
  requirements.

New material that does not clearly fit one of these rules MUST carry an
explicit license notice.

Contributions intentionally submitted for inclusion in the project are
provided under the license applicable to the material they modify or add.
